# Self-Guided Coding Mock Interview — 45 Minutes

## Setup (Before Starting)
1. Close all browsers, IDE hints, and GitHub Copilot
2. Open a blank text editor (Google Docs or plain text — no IDE autocomplete)
3. Set a visible timer
4. Have this script open on a separate screen/printout

---

## Problem Selection

Pick **2 problems** you haven't solved recently:
- **Problem 1 (Medium)**: 20 minutes
- **Problem 2 (Medium/Hard)**: 25 minutes

### Recommended Problem Sources
Use the LeetCode section README's "Priority 1" list, or pick from:
- Random Medium from a category you're weak in
- A Hard you've studied but not recently solved

---

## Timer Schedule

| Time | Activity |
|------|----------|
| 0:00 | Read Problem 1. Ask clarifying questions (aloud, to yourself) |
| 0:02 | Explain approach aloud BEFORE coding |
| 0:05 | Code the solution |
| 0:17 | Test with 2-3 examples. Fix bugs. |
| 0:20 | Analyze time/space complexity |
| 0:20 | Read Problem 2. Clarify. |
| 0:23 | Explain approach |
| 0:26 | Code the solution |
| 0:40 | Test. Fix bugs. |
| 0:43 | Complexity analysis |
| 0:45 | STOP. Self-evaluate below. |

---

## During the Mock — Behave Like a Real Interview

1. **Think aloud** — narrate your thought process continuously
2. **Ask questions** — even to yourself: "Can the input be empty? Can values be negative?"
3. **Write clean code** — meaningful variable names, not `i, j, k` for everything
4. **Test your code** — trace through with a concrete example
5. **Don't look anything up** — if stuck, describe your approach and move on
