## Key Interview Topics

### Must-Know for Google DRE (Gaming)
1. **Unity Lifecycle** — execution order of MonoBehaviour callbacks
2. **Physics** — collision vs trigger, raycasting, layer masks
3. **Design Patterns** — when to use Singleton vs Observer vs Object Pool
4. **Performance** — GC pressure, draw calls, profiling workflow
5. **Networking** — client-server vs P2P, state synchronization
6. **Render Pipelines** — URP vs HDRP trade-offs

### Google-Specific Topics
- Google Play Games Services integration
- Firebase for Unity (Analytics, Crashlytics, Remote Config)

- Android App Bundle for Unity
- Cloud gaming considerations
