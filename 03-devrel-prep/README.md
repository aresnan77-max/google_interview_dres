# DevRel Interview Preparation — Google DRE

## Google DRE Interview Process

```
Recruiter Screen → Phone Screen → Onsite (4-5 rounds) → Hiring Committee → Team Match
     (30 min)       (45 min)         (45 min each)          (review)        (chat)
```

### Round Types
| Round | Format | Focus |
|-------|--------|-------|
| Phone Screen | Coding on Google Docs | 1-2 Medium problems, communication style |
| Coding (x2) | Whiteboard / online IDE | Data structures, algorithms, clean code |
| System Design | Whiteboard discussion | Scalable architecture, API design |
| DevRel / Behavioral | Behavioral discussion | Googliness, developer empathy, communication |

### DRE vs SWE Interview Differences
| Aspect | SWE | DRE |
|--------|-----|-----|
| Coding Difficulty | Hard problems common | Medium difficulty, emphasis on clarity |
| Communication | Nice to have | **Critical** — explain while coding |
| System Design | Standard format | May include **API design** component |
| Behavioral | Standard | Heavy on **developer empathy** & **teaching** |
| Extra | None | May include **tech writing** or **presentation** |

## Evaluation Criteria

### Coding
- ✅ Correct and optimal solution
- ✅ Clean, readable, production-quality code
- ✅ Articulate approach BEFORE coding
- ✅ Test your solution with examples
- ✅ Discuss trade-offs and alternatives

### System Design
- ✅ Clarify requirements (functional + non-functional)
- ✅ High-level architecture with clear components
- ✅ Dive deep into 1-2 key components
- ✅ Discuss scalability, reliability, and trade-offs
- ✅ Consider developer experience (for DRE-specific designs)

### Behavioral (Googliness)
- ✅ Working collaboratively across teams
- ✅ Navigating ambiguity and making things happen
- ✅ Genuine passion for helping developers
- ✅ Intellectual humility — learning from mistakes
- ✅ Doing the right thing, even when difficult
